# Arcade Validation (retired)

The `dotnet/arcade-validation` repository and its internal Azure DevOps mirror and pipelines have been retired.

For current Arcade validation guidance, use [How to Validate a Private Build](https://github.com/dotnet/arcade/blob/main/Documentation/Policy/TestingMSBuildGuidance.md#how-to-validate-a-private-build). Known breaking changes must still follow the [Breaking Change Policy](../Policy/ChangesPolicy.md).
